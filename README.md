# Trishan Singha Roy’s personal website

A basic, single-page academic homepage built with plain HTML and CSS. GitHub Pages can serve the files directly; there is no build step or dependency installation.

Preview from the repository root:

```sh
python3 -m http.server 8765
```

Open <http://localhost:8765/>. Stop the server with Ctrl+C.

Edit the content and links in `index.html` and the styles in `assets/css/style.css`.

`.nojekyll` lets GitHub Pages serve the static files directly.
